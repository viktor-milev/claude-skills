Changelog — prompt-architect-fable

v1.0 — July 2026

First public release. A standalone Claude Fable 5 fork of the generative
prompt-architect: an execution-mode overlay (interactive vs. agentic) layered over the
10-bucket taxonomy, a re-derived and extended technique library (intent-context,
brevity/selectivity, and an agentic-execution block), the shared Fable-calibrated
architecture module (bound in lockstep with prompt-optimizer-fable), a surface
parameter (chat / code / cowork / harness), and run-settings recommendations on both
output formats. Fires only on explicit Fable invocation; the Opus original remains the
default.

Full design rationale is in the inline CHANGELOG section of SKILL.md.
